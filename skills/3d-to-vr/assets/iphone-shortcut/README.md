# Flat Headset pictures for a Home Screen shortcut

Use either PNG as the picture of the person-created [Flat Headset shortcut](../../references/iphone-functions.md#prepare-the-flat-headset-icon).
Both are 192 × 192 RGBA PNGs, copied without modification from the Android Flat Headset launcher assets at commit `209961bb3e446a7b70a450af47f23b8ab87e4e9c`:

- [flat-headset.png](flat-headset.png): [android/src/main/res/mipmap-xxxhdpi/flat_headset.png](https://github.com/Sparky-OS/flat-headset/blob/209961bb3e446a7b70a450af47f23b8ab87e4e9c/android/src/main/res/mipmap-xxxhdpi/flat_headset.png).
- [flat-headset-round.png](flat-headset-round.png): [android/src/main/res/mipmap-xxxhdpi/flat_headset_round.png](https://github.com/Sparky-OS/flat-headset/blob/209961bb3e446a7b70a450af47f23b8ab87e4e9c/android/src/main/res/mipmap-xxxhdpi/flat_headset_round.png).
