# ai-partners: lessons from the lanes of 25 October to 6 November 2026

Harvested by ORDER 429 from the accepted lane reports; each line names the lane it came from.
A trap gives its symptom, its cause, its fix and how the cause was found; a recipe gives the commands and the result to expect.

## Traps: the symptom, the cause, the fix, how it was found

- Symptom: a hosted model returns an empty answer for a nine-language review in one request. Cause: request size. Fix: one language per request (glm-5.3 worked; mistral-large-4 for Polish). Same limit seen with `repo_files` above about 11 KB (files near 10 KB work). (lane dkms-unsigned-370)
- Symptom: iso.org returns 403 to the fetch tool, a spoofed-user-agent curl is refused by the permission classifier, IEC webstore prices load by JavaScript. Cause: bot walls. Fix: read the catalogue through committee.iso.org mirror pages and webstore.iec.ch, record the date, never use browser tools or a spoofed agent. Found by: the 403 and the classifier refusal. (lane paid-standards-396)
- Symptom: listings priced CHF 0 (14496-12, 23008-12, 23009-1) while an actual purchase shows a stamp. Cause: the tools read a JavaScript price as zero. Fix: have a person re-read in a normal browser once before quoting a price. Prices seen: 23000-11 CHF 135, 14496-15:2024 CHF 227, 13818-1:2025 CHF 227, 21496-1 CHF 100, CTA-861-I USD 405 (non-member), CTA-861.3-A USD 74. (lane paid-standards-396)
- Symptom: a subagent's write of REPORT.md is refused ("Subagents should return findings as text"). Cause: the harness. Fix: return the full hand-back as the final message and summarise it in the task list. Same in fable-vision-304 and milton lanes. (lane skills-gap-323)
- Symptom: a skills search finds nothing for an error string that is written in a lessons file. Cause: only name plus description were indexed, and a description cannot hold every error string. Fix: a second index of the bodies, one chunk per section, searched together with the first and merged at 0.7 for the bodies; the symptom is written first in each lesson so the first 256 tokens carry it. Found by: the 28 of 157 symptoms the descriptions missed, 26 of which a body chunk answered (lane skills-bodies-438).
- Symptom: a body search returns step 4 of a procedure, or a command without the line that guards it. Cause: fixed-size windows cut inside lists and code blocks. Fix: chunk by heading, split an oversized section only between paragraphs or list items, never inside a numbered list, a table or a fenced block, and glue a paragraph ending in a colon to the block it introduces. Found by: reading every chunk boundary of a lessons file against its source lines; the check that each chunk's text equals its file lines first to last passed for all 1272 chunks (lane skills-bodies-438).
- Symptom: re-indexing after a merge embeds every chunk again, or leaves chunks of text that no longer exists. Cause: ids from line numbers or random ids. Fix: the id comes from the file, heading path and the sha256 of the chunk text; a moved chunk keeps its id and only its line numbers are rewritten in the payload; a changed chunk gets a new id and the old one is deleted. Found by: shifting a file by one line (35 payload updates, 0 embeddings), then editing one word (1 embedding, 1 deletion), then running twice (all unchanged, same ids) (lane skills-bodies-438).
- Symptom: link addresses and long heading paths leave little of the 256 tokens for the words that matter. Cause: a Markdown link is mostly its address, and the path repeats the file title. Fix: the embedded text keeps the link text and drops the address; the payload keeps the raw text. Windows of 128, 192 and 256 tokens gave the same routing within one symptom (top three 96 %, 97 %, 97 %), so the window of the model is the limit (lane skills-bodies-438).
