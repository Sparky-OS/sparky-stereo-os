# One more patch on a staged predecessor: plasma-workspace +stereo3d10 (ORDER 108 milestone 12 round 3, 2026-11-18)

Our plasma-workspace is built as a chain, one patch at a time, each step from the previous step's accepted stage and never from a work tree: +stereo3d9 (ORDER 684, one patch) is built from the published +stereo3d8 descriptor, +stereo3d10 from the staged +stereo3d9.
Check freshness first: written on 2026-11-18 from the job scripts `sparky-os/packages/plasma-workspace/build-job-defaults.sh` (+9) and `build-job-tray-menu.sh` (+10), Plasma 6.7.4, Lean Code 0.1.30.

## Recipe

1. **Copy the previous job script and move every pin one step on:** the folder of the predecessor's files (published pool for +9, the staged folder mounted at `/predecessor` for +10), its `.dsc` name and the SHA-256 of that `.dsc` (checked with `sha256sum -c`; the job then checks every file the `.dsc` lists against its own checksums before it copies it), the patch name, the changelog entry (`4:6.7.4-2+stereo3d10`, dated by `SOURCE_DATE_RFC2822`), the glob that `provenance-files.py` marks (`s10-*`, and the previous marks are kept by the job's merge loop), the version given to `lean.debian_prepare` (`...+stereo3d10+lc1`) and `SPARKY_LC_PREVIOUS_DIR` (the predecessor's folder: the link gate compares with those builds).
2. **The predecessor is an `+lc1` source:** `plain-from-lc.py --save-plan` makes the plain source back from it and saves the preserve plan; the new patch goes in `debian/patches` and at the end of `series`; `dpkg-source --before-build`, the changelog, the provenance marks, `reproducible.py normalize-tree`, `dpkg-source -b`, then `lean.debian_prepare`, build-dep and `dpkg-buildpackage` as the previous job does. The builder image is `sparky-lc-migration:20261020`; the job needs `/work`, `/repo` (published tree), `/predecessor`, `/toolkit` (sparky-os), `/archive` (sources.json and the keyrings under the names the job writes into apt's sources) and the host-provenance mounts of `build-provenance.sh` (`sparky_provenance_init IMAGE PACKAGE_DIR` prints them as `SPARKY_PROV_ARGS`: do not mount `/run/reproducible.py` twice). The whole family builds in about 100 minutes on 4 cores, the last gate (link and start) about half an hour of it.
3. **File by file against the predecessor** (memory do-not-remove-functionality): unpack every binary package of both, compare all files; for an ELF file compare its sections' contents, not its bytes. In +10 against +9: 5,553 files identical byte for byte; 84 ELF files differ in the build-id only; 58 ELF files differ in `.rodata` only (Qt's resource tree: three low bytes of each entry's last-modified time, 3 hours apart as the two recipe dates are); 17 PNG files differ in a time field; 1 ELF differs in content (the tray plugin, the point of the patch); the documentation, changelog, copyright and lc manifests differ as records. List every path.
4. **A patch's autotest** goes into the source's own `autotests` (CMake under `BUILD_TESTING`); Debian's `override_dh_auto_test` does not run them in the build (no `ungrabtest` in the build log), so run it once in a throwaway container with the same files and say so.

## Traps

- **Symptom:** `docker: Duplicate mount point: /run/reproducible.py`. **Cause:** `SPARKY_PROV_ARGS` already carries it. **Fix:** do not mount it again.
- **Symptom:** a waiting loop `while pgrep -f run-ws10.sh` never ends. **Cause:** `pgrep -f` matches the shell that runs the loop. **Fix:** `docker wait NAME` or `docker ps`.
- **Symptom:** the job's output ends at "Prepared source" for an hour. **Cause:** nothing is wrong: the compile prints to `/work/build.log`, not to the job's output. **Fix:** read that file.
- **Symptom:** counting menus by looking for popup windows counts the pop-ups of left clicks and the tray's own menu too. **Fix:** log `workspace.windowAdded` from a KWin script (`popupWindow`, geometry) and count windows of the menu's size, or count `contextualActionsAboutToShow` in the applet; a left click clears the stale press that causes the defect, so a test with left clicks in between passes on the broken tray.
